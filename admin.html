🗄️ Fonte de Dados

Escolha onde os dados do sistema são armazenados. localStorage é indicado para testes (dados no navegador); Banco de dados usa a API/servidor (produção). Não sabe como configurar o banco? 📖 documentação aqui.

⚠️ Ao trocar a fonte de dados, os dados não são migrados automaticamente entre localStorage e banco. Use a mesma fonte de forma consistente. A migração de dados é uma etapa separada (ver estudos da issue #144).
📖 Como conectar ao banco de dados — passo a passo

Guia rápido para ligar o SCTEC ao PostgreSQL via backend. Detalhes completos em docs/GUIA_CONEXAO_BANCO_144.md.

1. Pré-requisitos

Node.js 18+ e Podman instalados. Confira no terminal: node --version, podman --version.

2. Subir o PostgreSQL (Podman)
podman machine start
podman compose -f server/compose.yaml up -d
podman ps   # deve listar "sctec-postgres" na porta 5432

O schema (server/db/schema.sql) é aplicado automaticamente na primeira subida.

3. Configurar e rodar o backend
cd server
Copy-Item .env.example .env   # ajuste JWT_SECRET e a senha do banco
npm install
npm start                     # http://localhost:3000 (API em /api/v1)

Teste a saúde: curl http://localhost:3000/api/v1/health → deve responder up.

4. Criar o primeiro usuário (org + admin)
POST /api/v1/auth/register
{ "nome":"Admin", "email":"admin@exemplo.com", "senha":"secreta123", "nomeOrg":"Minha Empresa" }

Guarde o token retornado.

5. Apontar o SCTEC para o banco
  1. Aqui em Fonte de Dados, selecione Banco de dados.
  2. Informe a URL http://localhost:3000/api/v1 e clique em Testar conexão.
  3. Clique em Salvar fonte de dados (a página recarrega).
  4. No console do navegador (F12), informe o token: ApiProvider.definirToken("SEU_TOKEN").
6. Verificar

Crie um Pedido de Venda e confirme no banco:

podman exec -it sctec-postgres psql -U sctec -d sctec -c "SELECT id, titulo, total FROM pedidos_venda;"
Para voltar ao modo de testes, selecione localStorage e salve. Lembre-se: os dados não migram automaticamente entre as fontes.
